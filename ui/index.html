Commands

Slash commands at your fingertips

Type a command in Claude Code to trigger the right workflow instantly.

/tdd Launch the test-driven development loop — write failing tests, implement, refactor. testing
/plan Generate a dependency-ordered implementation plan before writing any code. planning
/code-review Run a thorough quality and security review against the current diff. quality
/e2e Generate and run end-to-end tests via Playwright for the feature in scope. testing
/build-fix Diagnose and repair CI/build failures with language-specific build resolvers. ops
/skill-create Auto-generate a skill from git history and commit patterns in this repo. meta
/instinct-status Show the current state of the continuous-learning instinct system. learning
/sessions List and resume previous Claude Code sessions with persisted context. sessions
Hooks

Smart automation on every event

Hooks run automatically in response to Claude Code lifecycle events — no manual triggers needed.

🚀

SessionStart

Loads persisted context, injects memory, detects package manager, and primes Claude with project conventions on every session start.

💾

SessionEnd

Persists key decisions, learned patterns, and session state so Claude picks up exactly where you left off.

🔒

PreToolUse — Secret Detection

Scans outgoing tool calls for leaked secrets, API keys, and credentials before they leave your machine.

✨

PostEdit — Auto-Format

Runs the right formatter and linter for each edited file automatically after every save. Configurable via ECC_HOOK_PROFILE.

⚡

PostToolUse — Typecheck

Triggers incremental type-checking after edits to TypeScript files, catching errors inline without a manual build step.

🗜️

Strategic Compaction

Monitors context usage and triggers smart context compaction before hitting limits, preserving the most relevant information.

Hook strictness profiles

minimal — essentials only standard — recommended strict — all hooks active

Set ECC_HOOK_PROFILE=minimal or disable individual hooks via ECC_DISABLED_HOOKS.

Install

Up and running in seconds

Choose your preferred install method. Full profile gives you everything; minimal is a clean starting point.

# macOS / Linux — full profile (recommended)
curl -sSL https://raw.githubusercontent.com/affaan-m/everything-claude-code/main/install.sh | bash -s -- --profile full

# Windows (PowerShell)
irm https://raw.githubusercontent.com/affaan-m/everything-claude-code/main/install.ps1 | iex
# Install globally via npm
npm install -g ecc-universal

# Or with TypeScript support
npm install ecc-universal
npx ecc typescript
# Clone and run the apply script
git clone https://github.com/affaan-m/everything-claude-code.git
cd everything-claude-code

# Apply with your chosen profile: minimal | standard | full
node scripts/install-apply.js --profile full
minimal
Core hooks + essential rules. Zero noise, maximum signal.
lightweight
standard ✦
All agents, skills, commands + hooks. Recommended for most projects.
recommended
full
Everything — MCP configs, AgentShield, ECC 2.0 alpha, all language rules.
complete
